# ЕГЭ: задачи на Kotlin

Шесть авторских тренировочных задач по типам ЕГЭ. Это не копии официальных заданий: параметры вынесены во входные файлы, чтобы проверять программу на разных данных.

Нужен **JDK 17 или новее** (рекомендуется 21). Kotlin и Gradle отдельно устанавливать не нужно. При первом запуске нужен интернет для загрузки Gradle и зависимостей.

## Как решать

1. Открой условие в `tasks/`.
2. Напиши решение в `solutions/<номер>/Main.kt`, внутри `fun main()` без `package`.
3. Запусти проверку из корня репозитория:

```bash
./gradlew checkTask -Ptask=07-1 --console=plain
```

Windows PowerShell:

```powershell
.\gradlew.bat checkTask -Ptask=07-1 --console=plain
```

По умолчанию проверяется `07-1`. Компилируется только выбранная задача, ошибки в других заготовках ей не мешают.

## Ввод и вывод

Вход подаётся автоматически из `tests/<номер>/01.in.txt`. Ответ сравнивается с `01.out.txt`. Новая пара таких файлов автоматически становится новым тестом.

Пример чтения строки чисел (это пример синтаксиса, не решение задачи):

```kotlin
fun main() {
    val numbers = readln().trim().split(Regex("\\s+")).map { it.toLong() }
    println(numbers.sum())
}
```

Для № 26 удобно читать много строк через ``System.`in`.bufferedReader()``. Также можно читать `java.io.File("input.txt")`: проверка кладёт туда данные текущего теста. Ответ всегда выводи через `print` / `println`, без пояснений вроде «Ответ:». Для больших произведений используй `Long`.

Пробелы и переносы строк в ответе считаются равнозначными. Числа и остальные символы должны совпадать точно. Каждый тест запускается отдельно, лимит 3 секунды. При неверном ответе, падении или зависании команда завершается с ненулевым кодом. Подробные результаты лежат в `build/checkTask/`.

Заготовки намеренно пустые: до написания решения тесты будут красными. Готовые решения не включены. Тесты открытые, это тренажёр, а не защита от списывания. Проверка запускает локальный код с правами пользователя.
