# 07-2. Передача звука

Авторская тренировочная задача по типу № 7 ЕГЭ, адаптированная для программирования.

Несжатая запись длится T секунд. Частота дискретизации F отсчётов в секунду, глубина B бит, количество каналов K. Скорость передачи R бит/с. Найдите минимальное целое количество секунд для передачи всей записи. Служебные данные отсутствуют.

## Вход

Одна строка: F B K T R. 1 ≤ F ≤ 192000; 1 ≤ B ≤ 32; 1 ≤ K ≤ 8; 1 ≤ T ≤ 10000; 1 ≤ R ≤ 1000000000.

## Выход

Одно целое число — время с округлением вверх.

Лимит: 3 секунды на тест, память JVM 256 Мбайт.

## Пример

Ввод:
```text
44100 16 2 60 1000000
```

Вывод:
```text
85
```
