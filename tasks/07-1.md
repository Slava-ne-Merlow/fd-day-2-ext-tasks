# 07-1. Объём изображения

Авторская тренировочная задача по типу № 7 ЕГЭ, адаптированная для программирования.

Изображение содержит W × H пикселей и использует палитру из C цветов. Каждый пиксель кодируется одинаковым минимально возможным целым числом бит. Заголовка и сжатия нет. Найдите минимальный объём памяти в целых Кбайтах, округляя итог вверх. 1 Кбайт = 1024 байта, 1 байт = 8 бит.

## Вход

Одна строка: W H C. 1 ≤ W, H ≤ 100000; 2 ≤ C ≤ 65536.

## Выход

Одно целое число — объём в Кбайтах.

Лимит: 3 секунды на тест, память JVM 256 Мбайт.

## Пример

Ввод:
```text
128 128 256
```

Вывод:
```text
16
```
