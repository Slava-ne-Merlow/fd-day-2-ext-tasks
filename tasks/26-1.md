# 26-1. Архив на диске

Есть диск вместимостью S и N пользовательских файлов. Каждый файл хранится целиком и может быть выбран один раз.

Нужно разместить максимально возможное количество файлов. Среди наборов с таким количеством найди наибольший размер отдельного файла, который можно включить в набор.

## Вход

Первая строка: S N. Затем N строк с размерами файлов.
В исходном условии: 1 ≤ S ≤ 10000, 1 ≤ N ≤ 6000, размер каждого файла от 1 до 100.

## Выход

Два целых числа через пробел: максимальное количество файлов, затем наибольший допустимый размер файла при этом количестве.

## Пример

```text
100 4
80
30
50
40
```

Ответ для примера: `2 50`.

## Ввод и вывод

Вход подаётся автоматически из `tests/26-1/01.in.txt`. Ответ сравнивается с `01.out.txt`. Новая пара таких файлов автоматически становится новым тестом.

Пример чтения строки чисел (это пример синтаксиса, не решение задачи):

```kotlin
fun main() {
    val numbers = readln().trim().split(Regex("\\s+")).map { it.toLong() }
    println(numbers.sum())
}
```

Удобно читать много строк через ``System.`in`.bufferedReader()``. Также можно читать `java.io.File("input.txt")`: проверка кладёт туда данные текущего теста. Ответ всегда выводи через `print` / `println`, без пояснений вроде «Ответ:». Для больших произведений используй `Long`.
