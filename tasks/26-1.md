# 26-1. Архив на диске

Авторская тренировочная задача по типу № 26 ЕГЭ, адаптированная для программирования.

На диске свободно S единиц памяти. Даны размеры N файлов. Выберите как можно больше файлов, суммарный размер которых не превосходит S. Среди таких наборов найдите наибольший возможный размер самого большого выбранного файла. Каждый файл можно взять один раз.

## Вход

Первая строка: S N. Далее N строк, по одному размеру файла. 1 ≤ S ≤ 10^9; 1 ≤ N ≤ 100000; размеры от 1 до 10^9.

## Выход

Два числа: максимальное количество файлов и наибольший возможный размер файла в таком наборе. Если ничего не помещается, выведите 0 0.

Лимит: 3 секунды на тест, память JVM 256 Мбайт.

## Пример

Ввод:
```text
100 5
10
20
30
40
80
```

Вывод:
```text
4 40
```
