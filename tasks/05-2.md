# 05-2. Преобразование троичной записи

Представь положительное целое N в системе счисления с основанием 3.
Дополни полученную строку справа:

- Если N делится на 3 без остатка, добавь копию двух последних символов этой строки.
- Иначе найди остаток N от деления на 3, умножь его на 5 и добавь троичную запись полученного произведения.

Число, заданное итоговой троичной строкой, обозначим R.
Напиши программу, которая найдёт наибольшее достижимое R в пределах до 173 включительно.
Выведи его десятичное значение.
