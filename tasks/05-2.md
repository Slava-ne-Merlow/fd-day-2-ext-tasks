# 05-2. Преобразование троичной записи

Источник: [«Решу ЕГЭ», тип 5, № 59827](https://inf-ege.sdamgia.ru/problem?id=59827).
На сайте указан источник: основной ЕГЭ 20.06.2023, Дальний Восток.
Ниже — краткое изложение условия; алгоритм и числа сохранены.

Представь положительное целое N в системе счисления с основанием 3.
Дополни полученную строку справа:

- Если N делится на 3 без остатка, добавь копию двух последних символов этой строки.
- Иначе найди остаток N от деления на 3, умножь его на 5 и добавь троичную запись полученного произведения.

Число, заданное итоговой троичной строкой, обозначим R.
Напиши программу, которая найдёт наибольшее достижимое R в пределах до 173 включительно.
Выведи его десятичное значение.

## Формат проверки

Входных данных нет: все параметры заданы выше. Файл `tests/05-2/01.in.txt` пустой.
Программа должна вычислить и напечатать одно целое число, без пояснений.
Пиши решение в `solutions/05-2/Main.kt`, внутри `fun main()`.

```bash
./gradlew checkTask -Ptask=05-2
```

Один тест проверяет ответ исходной задачи. Это проверка результата, а не способа решения: вместо переписывания ответа из `.out.txt` реализуй алгоритм и поиск.
