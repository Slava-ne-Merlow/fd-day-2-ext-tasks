# 08-2. Номер слова

Авторская тренировочная задача по типу № 8 ЕГЭ, адаптированная для программирования.

Все слова одинаковой длины из букв А, К, Л, О записаны в лексикографическом порядке: А < К < Л < О. Нумерация начинается с 1. Найдите номер данного слова. Например, для длины 2 список начинается: АА, АК, АЛ, АО, КА. Разберите входное слово на отдельные символы.

## Вход

Одна строка — слово длины от 1 до 15. Только заглавные русские буквы А, К, Л, О.

## Выход

Номер слова в списке слов его длины.

Лимит: 3 секунды на тест, память JVM 256 Мбайт.

## Пример

Ввод:
```text
А
```

Вывод:
```text
1
```
