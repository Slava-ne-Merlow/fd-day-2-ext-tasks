# 08-2. Номер слова УКАРА

Источник: [«Решу ЕГЭ», тип 8, № 3230](https://inf-ege.sdamgia.ru/problem?id=3230).
Условие кратко изложено своими словами, правила сохранены.

Рассмотри все последовательности из пяти символов алфавита А, К, Р, У. Повторы разрешены. Последовательности упорядочены по алфавиту (А < К < Р < У), их номера начинаются с 1.

Напиши программу, определяющую позицию УКАРА в этом списке. Вход отсутствует; выведи одно целое число.
