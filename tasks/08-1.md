# 08-1. Слова из букв «СЛОН»

Посчитай последовательности длины 5 из алфавита С, Л, О, Н, в которых С встречается единственный раз. Остальные символы разрешено повторять без ограничений. Осмысленность полученных слов не важна.

Напиши программу, вычисляющую количество таких последовательностей. Вход отсутствует; выведи одно целое число.
