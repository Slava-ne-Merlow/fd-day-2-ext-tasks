# 08-1. Слова с одной буквой А

Авторская тренировочная задача по типу № 8 ЕГЭ, адаптированная для программирования.

Составляются слова длины N из букв А, Б, В, Г. Буквы можно повторять. Посчитайте слова, содержащие ровно одну А и не содержащие двух подряд идущих Б. Слово — любая последовательность, не обязательно осмысленная.

## Вход

Одно число N, 1 ≤ N ≤ 10.

## Выход

Количество подходящих слов.

Лимит: 3 секунды на тест, память JVM 256 Мбайт.

## Пример

Ввод:
```text
1
```

Вывод:
```text
1
```
