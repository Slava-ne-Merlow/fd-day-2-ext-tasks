# 26-2. Расписание аудитории

Авторская тренировочная задача по типу № 26 ЕГЭ, адаптированная для программирования.

Даны заявки на занятия в одной аудитории. Каждая заявка содержит время начала и окончания. Выберите максимальное число непересекающихся занятий. Занятие может начинаться точно в момент окончания предыдущего.

## Вход

Первая строка: N (1 ≤ N ≤ 100000). Далее N строк: начало и конец, 0 ≤ начало < конец ≤ 10^9. Заявки могут повторяться; каждую можно использовать один раз.

## Выход

Одно число — максимальное количество занятий.

Лимит: 3 секунды на тест, память JVM 256 Мбайт.

## Пример

Ввод:
```text
5
0 10
0 2
2 4
4 6
6 10
```

Вывод:
```text
4
```
