# 26-2. Покупки со скидкой

Источник: [«Решу ЕГЭ», тип 26, № 29674](https://inf-ege.sdamgia.ru/problem?id=29674).
Условие кратко изложено своими словами, правила сохранены.

Для покупки известны цены всех товаров. Товары ценой до 50 рублей включительно оплачиваются полностью и не участвуют в нумерации товаров для скидки.

Среди остальных товаров каждый второй получает скидку 25%. Продавец вправе переставлять товары и выбирает порядок с минимальной суммарной скидкой. Итоговую сумму оплаты округляют вверх до целого рубля.

## Вход

Первая строка содержит количество товаров N. Далее следуют N строк с целыми ценами в рублях.

## Выход

Напечатай итоговую сумму оплаты и исходную цену самого дорогого товара, получившего скидку. Раздели два целых числа пробелом.

## Пример из источника

```text
6
125
50
490
215
144
320
```

Ответ для примера: `1277 144`.

## Проверка
