# 05-1. Два бита проверки

Источник: [«Решу ЕГЭ», тип 5, № 8094](https://inf-ege.sdamgia.ru/problem?id=8094).
На сайте указан источник: досрочный ЕГЭ 05.05.2015.
Ниже — краткое изложение условия; алгоритм и числа сохранены.

Возьми положительное целое N и представь его в системе счисления с основанием 2.
Посчитай единицы в полученной строке. Добавь справа бит: 0 при чётном количестве единиц, 1 при нечётном.
Повтори эту операцию над уже дополненной строкой.
Интерпретируй итоговую строку как двоичное число R.

Напиши программу, которая найдёт наименьшее достижимое R, строго большее 43.
Выведи его десятичное значение.

## Формат проверки

Входных данных нет: все параметры заданы выше. Файл `tests/05-1/01.in.txt` пустой.
Программа должна вычислить и напечатать одно целое число, без пояснений.
Пиши решение в `solutions/05-1/Main.kt`, внутри `fun main()`.

```bash
./gradlew checkTask -Ptask=05-1
```

Один тест проверяет ответ исходной задачи. Это проверка результата, а не способа решения: вместо переписывания ответа из `.out.txt` реализуй алгоритм и поиск.
