# 05-1. Два бита проверки

Возьми положительное целое N и представь его в системе счисления с основанием 2.
Посчитай единицы в полученной строке. Добавь справа бит: 0 при чётном количестве единиц, 1 при нечётном.
Повтори эту операцию над уже дополненной строкой.
Интерпретируй итоговую строку как двоичное число R.

Напиши программу, которая найдёт наименьшее достижимое R, строго большее 43.
Выведи его десятичное значение.
